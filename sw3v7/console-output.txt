1. БЛОК USING
Відкрито порт COM1 (імітація).
COM1: передано 3 байт — 010203.
Порт COM1 закрито: Dispose.
Вийшли з using — порт уже закрито.

2. ЯВНИЙ DISPOSE
Відкрито порт COM2 (імітація).
COM2: передано 2 байт — 0A14.
Порт COM2 закрито: Dispose.
Повторний Dispose не повинен закривати порт вдруге:
Стан: відкрито = False, звільнено = True.
Передавання після Dispose відхилено.

3. БЕЗ DISPOSE — ФІНАЛІЗАТОР
Відкрито порт COM3 (імітація).
COM3: передано 1 байт — FF.
Запускаємо GC.Collect().
Порт COM3 закрито: фіналізатор.
Фіналізацію завершено.
